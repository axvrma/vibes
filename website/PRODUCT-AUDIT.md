## Vibes 2.3 additions

- **External libraries:** `server/src/services/media-library.ts`, migration 005 and `dashboard/src/app/pages/libraries.page.*`. Persistent jobs, idempotent refresh, read-only roots, missing-state preservation and folder categories. `scripts/docker-smoke.mjs` exercises actual FFmpeg/FFprobe and authorized streaming on disposable fixtures. No automatic transcoding or scheduled scans claimed.
- **Two playback modes:** `mode_selection_screen.dart`, Android document-tree access and Apple security-scoped folder bookmarks. Browser Local Mode remains unavailable. Native permissions and background playback still need hardware validation.
- **Actual dashboard capture:** `public/media/vibes-libraries.png` comes from the running disposable Docker integration environment. Its visible counts are labeled as test data. The original interactive dashboard remains labeled as a concept demonstration.
- **Personal library:** paginated API filters, Flutter library/search/favorites/continue-watching UI. Progress means latest saved playback position, not accumulated watch time.
- **Identity:** generated semantic tokens preserve the original rose/violet website palette and vector wordmark. Inter is bundled under its OFL license. No public social features or advertising have been added.
