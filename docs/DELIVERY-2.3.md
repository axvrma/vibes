# Vibes 2.3 delivery

1. **Baseline audit:** clean HEAD matched `2d99f038eca82901bd787eb697017c9aa4570941`. [Audit/matrix](V2.3-AUDIT.md).
2. **Implementation:** extends the existing Flutter, Angular, Express/SQLite, NGINX and React architecture; no framework replacement or production deployment.
3. **Changed modules:** `app/` repositories, playback/feed, notes/library/settings, platform bridges and assets; `server/` schema/repositories/scanner/security/routes/CLI/tests; `dashboard/` shell/pages/dialogs/API models; `infra/`; `website/`; canonical `brand/`, generators and documentation. [Full file manifest](CHANGES-2.3.txt).
4. **Migration:** additive `005_media_libraries`; existing uploaded IDs/state preserved, indexed source fields added, SQLite-safe snapshots and query indexes.
5. **API:** roots/libraries/scans/status/cancel/history, scoped media-ticket issuance, paginated personal-library queries, metadata/bulk edits and merged state updates. [Contracts](API-2.3.md).
6. **Flutter:** both modes retained, recursive stable local discovery/state, draft-preserving notes, personal library/search/favorites/continue watching, adaptive navigation, keyboard/seek/mute/speed/replay, controlled manual caching and offline diagnostics.
7. **Dashboard:** overview, real Media Libraries jobs/results, source/availability/tag/category/search filters, pagination, grid/table switch, metadata dialog and bulk categories/tags, accessible dialogs and upload retry.
8. **Media engine:** trusted read-only roots, descriptor-relative Linux file access, incremental probes/thumbnails, stable rename matching, conservative missing handling, persistent serial queue, bounded processors and safe restart/cancel.
9. **Brand:** canonical dark/light semantic tokens, 9 vector masters, launcher/adaptive/Apple/browser/Windows exports, splash resources and locally licensed Inter/Roboto. [Brand](../brand/README.md).
10. **Website:** original hero/feed demos preserved; accurate acquisition modes/external library explanations, actual labeled dashboard capture, updated audit and rerun quality checks.
11. **Security:** inactive-account/visibility checks, header or narrowly scoped ticket media authorization, no bearer query tokens, validated ranges/inputs, controlled CORS, CSRF protections for refresh cookies, private logging and SQLite online backup. Renderer/fonts self-hosted with browser verification.
12. **Validation:** 34 backend tests, 53 dashboard tests, 13 Flutter tests, 10 website unit tests, 23 applicable website E2E tests; analyzer, production web/Angular/website/API builds, Android debug APK and Docker/browser integration pass. [Complete evidence](VALIDATION-2.3.md).
13. **Performance:** 2,000 unchanged synthetic records scanned in 2.00 s in the final benchmark; 48-item query median 0.69 ms / p95 1.78 ms. No speedup or native playback profiling claim. Removed a 1,993,404-byte icon font; dashboard bundle warning disclosed.
14. **Docker upgrade:** back up first, configure `infra/.env`, run `docker compose config -q` and `docker compose up -d --build` from `infra/`. Optional SSD uses the explicit `docker-compose.media.yml` override. Do not change the existing project/volume name. [Commands](UPGRADE-2.3.md).
15. **Backup/rollback:** online DB backup CLI for the new image; cold full-volume backup before first upgrade. Restore the complete pre-upgrade data snapshot while stopped, then the recorded old images/configuration. No active-DB file copying or `down -v`. [Procedure](UPGRADE-2.3.md).
16. **Limits:** unverified native/hardware surfaces, no release signing/TLS deployment, no transcoding/resumable uploads/scheduled scans, explicit root identity review on replacement, local/provider fingerprint limits, ticket renewal and development-tool audit findings. [Details](VALIDATION-2.3.md#known-limits-and-release-blockers).
17. **Assessment:** implemented and locally validated release candidate. General cross-platform production release remains blocked on Apple/Windows/Linux builds and real-device permission/playback/lifecycle/performance acceptance.
